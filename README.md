# Iris Flower Classification

## Project Overview

This project uses Machine Learning to classify Iris flowers into different species based on their measurements.

## Dataset

The Iris dataset contains flower measurements such as:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target classes are:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab
- Jupyter Notebook

## Machine Learning

The dataset is processed and used to train a Machine Learning classification model. The trained model predicts the species of an Iris flower based on its input measurements.

## Project Workflow

Dataset → Data Preprocessing → Model Training → Testing → Prediction → Result

The Iris Flower Classification project demonstrates how Machine Learning can be used to classify flowers based on their physical measurements.
